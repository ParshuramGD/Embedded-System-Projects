# Embedded System Projects

A collection of embedded systems projects demonstrating firmware development, hardware interfacing, communication protocols, and IoT applications using industry-standard microcontrollers and development tools.

The projects cover concepts including:

- Embedded C/C++
- STM32 & ESP32 Development
- Arduino Programming
- Communication Protocols (UART, SPI, I²C, CAN)
- Sensor Interfacing
- IoT Applications
- Real-Time Data Monitoring
- Modular Firmware Design
- Embedded Debugging

## Projects

| Project | Description |
|---------|-------------|
| **CAN-Based Battery Monitoring System** | Distributed battery monitoring using Arduino UNO, ESP32, CAN Bus, SPI, I²C, and Blynk IoT. |
| **Real-Time Temperature Monitoring System** | STM32 and ESP32 based temperature monitoring using UART communication and Blynk IoT. |

More embedded projects covering communication protocols, embedded firmware, RTOS, and IoT applications will be added over time.
